## 更新するとき
ファイルを GitHub にアップロードし直すときは、**版の数字をそろえて上げる**（古いキャッシュと新しいファイルが混ざって画面がくずれるのを防ぐため）。
- かんたんな方法（v9.8 から）：このフォルダで `python bump.py 9.9` → sw.js の `VERSION`、data.js の `APP_VER`、HTML の css・js の `?v=` を全部そろえて書きかえる。v10.0 からは sw.js の `APP_FILES`（オフライン用のファイル一覧）も、フォルダの中身から自動で作りなおす（ファイルを足したり消したりしたら、bump.py を動かすだけでよい）
- 手でやるとき：sw.js の `VERSION`、data.js の `APP_VER`、index.html と sagase.html の `?v=`
- mp3 には `?v=` をつけない。曲を入れかえるときはファイル名を変えて、app.js の BGM_FILES（スロットは slot.html）と sw.js は直さなくてよい（mp3 はキャッシュしない）

## 猫を増やすとき
1. 4枚の透過PNG（体・しっぽの先・服・手袋。4枚とも同じ大きさ、高さ813）をほかのファイルと同じ場所に入れる。服はオレンジ、手袋は茶色にそろえる（着せかえの色はフィルターで変えるため）
2. data.js の `CATS` に1匹ぶん書き足す（名前・絵の幅・頭の位置・タップの当たり判定）
3. `python bump.py ○○` で版を上げる（sw.js の一覧には自動で入る）

## v8.6 で変わったこと
- さんぽモード（GPS）を追加：ホームの「歩数」→「🐾 さんぽモード（GPS）」
  - アプリを開いたまま歩くと、地図（OpenStreetMap）に道のりを描き、距離 ÷ 歩幅（身長×0.45）で歩数にする。1000歩ごとのごほうびは今までと同じ
