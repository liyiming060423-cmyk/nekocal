# ねこカロリー（PWA版）

食べたものの写真とカロリーを記録すると、目標との差で猫が太ったり痩せたりする育成ゲームです。
やせすぎると骸骨に、食べすぎると爆発します。

スマホのホーム画面に追加すると、アプリのようにアイコンから全画面で起動できます。iPhone・Android の両方で使えます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（画面・猫の描画・記録の処理がすべて入っている） |
| `manifest.webmanifest` | アプリ名・アイコン・全画面表示などの設定 |
| `sw.js` | オフラインでも起動できるようにする仕組み（Service Worker） |
| `icons/` | アプリのアイコン |

## 公開する手順（GitHub Pages・無料）

1. GitHub にログインし、右上の「+」→「New repository」
2. リポジトリ名を入力（例：`nekocal`）、**Public** を選んで「Create repository」
3. 「uploading an existing file」をクリックし、このフォルダの中身（`index.html`、`manifest.webmanifest`、`sw.js`、`icons` フォルダ、`README.md`）をすべてドラッグ＆ドロップ →「Commit changes」
4. リポジトリの「Settings」→ 左メニュー「Pages」
5. 「Branch」で `main` と `/ (root)` を選んで「Save」
6. 1〜2分待つと、上に `https://ユーザー名.github.io/nekocal/` のURLが表示される

このURLをチームに共有すれば、全員が同じアプリを使えます。

## スマホに入れる手順

**iPhone（Safari）**
1. 上のURLを Safari で開く
2. 下の共有ボタン（□に↑）→「ホーム画面に追加」→「追加」

**Android（Chrome）**
1. 上のURLを Chrome で開く
2. 右上の「︙」→「アプリをインストール」または「ホーム画面に追加」

## パソコンで試す方法

`index.html` をダブルクリックしてもゲームは動きます。ただし、ホーム画面への追加とオフライン起動は https のサイトでしか動かないため、確認したいときはこのフォルダで次を実行し、ブラウザで `http://localhost:8000` を開きます。

```
python -m http.server 8000
```

## 更新するとき

1. `index.html` などを書き換えて GitHub にアップロードし直す
2. `sw.js` の `const VERSION = 'v1';` の数字を `v2`、`v3` のように上げる（上げないと、スマホに古い版が残ることがある）

## 注意

- 記録はそれぞれのスマホの中に保存されます。機種変更・ブラウザのデータ削除で消えます
- カロリーは手入力です（写真からの自動推定は今後追加予定）
- 初回起動時はサンプルデータが表示されます。「サンプルを消して始める」から自分の設定に変えてください
