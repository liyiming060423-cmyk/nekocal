# にゃんカロ

ごはんを撮って、歩いて、筋トレして育てる猫の育成ゲーム（PWA）。

## 更新するとき
ファイルを GitHub にアップロードし直したら、**3か所の版の数字をそろえて上げる**：sw.js の `VERSION`、data.js の `APP_VER`、index.html と sagase.html・slot.html の `?v=`（baseball.html は ?v= なし）（古いキャッシュと新しいファイルが混ざって画面がくずれるのを防ぐため）。

## 猫を増やすとき
1. 4枚の透過PNG（体・しっぽの先・服・手袋。4枚とも同じ大きさ、高さ813）をほかのファイルと同じ場所に入れる。服はオレンジ、手袋は茶色にそろえる（着せかえの色はフィルターで変えるため）
2. data.js の `CATS` に1匹ぶん書き足す（名前・絵の幅・頭の位置・タップの当たり判定）
3. sw.js の一覧に4枚を足して、VERSION を上げる

## v8.6 で変わったこと

## v9.2 で変わったこと（AIの使いすぎ防止）
- AI中継 Worker（nekocal-ai）に回数の上限。数は D1 の nekocal-db（対戦と同じDB）の表 ai_use に入る（表は Worker が自動で作る）
  - 1台のスマホ：1日20回・1分5回／同じIP：1日100回（学校のWi-Fiはみんな同じIP）／全員の合計：1日300回（日本時間）
  - 上限をこえると 429 と日本語の理由を返す → アプリはその文を出して「手で入力してね」
  - IP はその日だけのハッシュにして保存（そのままは残さない）。7日より前の記録は自動で消える
  - JPEG 以外の画像は受けつけない
  - 数字を変えるときは Worker の LIMIT（コードの上のほう）
- アプリ：AIに送るとき端末ID（?d=）をつける。このブラウザに1つ（localStorage の nyankalo-dev、バックアップには入れない）
  - しらべ終わったら「今日のAIあと○回」を出す
- 更新の順番：Worker を先 → アプリ。Worker は d なし（古いアプリ）でも動く（IPと全員の上限だけかかる）
- Worker に DB のバインディングが無いと、AIは動くが上限がかからない（返事に "limit": "off"）。アプリに「今日のAIあと○回」が出れば上限が効いている
