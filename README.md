# にゃんカロ

ごはんを撮って、歩いて、筋トレして育てる猫の育成ゲーム（PWA）。

## ファイル

## 更新するとき
ファイルを GitHub にアップロードし直したら、**3か所の版の数字をそろえて上げる**：sw.js の `VERSION`、data.js の `APP_VER`、index.html と sagase.html・slot.html の `?v=`（baseball.html は ?v= なし）（古いキャッシュと新しいファイルが混ざって画面がくずれるのを防ぐため）。

## 猫を増やすとき
1. 4枚の透過PNG（体・しっぽの先・服・手袋。4枚とも同じ大きさ、高さ813）をほかのファイルと同じ場所に入れる。服はオレンジ、手袋は茶色にそろえる（着せかえの色はフィルターで変えるため）
2. data.js の `CATS` に1匹ぶん書き足す（名前・絵の幅・頭の位置・タップの当たり判定）
3. sw.js の一覧に4枚を足して、VERSION を上げる

## v8.1 で変わったこと

- 写真つきでごはんを記録すると、ミニゲームの報酬つきプレイ +1回（1日3回まで）

## v8.2 で変わったこと
- 画面ごとのBGM（タイトル・ホーム系・ショップ系・トレーニング）。せってい に「BGM」のオン・オフ。ミニゲーム中とアプリが裏にあるときは止まる
- スマホはタップするまで音を出せないので、タイトル画面の右上の🔈ボタンかスタートで鳴りはじめる
- mp3 は service worker を通さない（iPhone で鳴らなくなることがあるため）。オフラインのときはBGMなし

## v8.3 で変わったこと
- 猫バトル（対戦・PvP）：ジムの絵（⚔️ 対戦）からひらく。順位の近い猫と戦う非同期対戦（相手の猫はAIが動かす）
  - 毎ターン3枚のスキルカードから1枚えらぶ（ジャブ・ストレート・ガード・カウンター・ため、ゲージ3で必殺ねこパンチ）。最大5ラウンド
  - ちから＝ダメージ、すばやさ＝先に動く・よける、たいりょく＝HP。ジムの能力と装備がそのまま使われる
  - 1日5回（ミニゲームの回数とは別）。勝ち +30・負け +5 コイン。5回のあとは練習試合（レート・コインなし）
  - レートと回数はサーバー（Cloudflare Worker「nekocal-battle」＋ D1）が計算。サーバーの URL は data.js の BATTLE_API
  - 人数が少なくても遊べるように CPU猫が20匹いる（ランキングに「CPU」と出る）
  - 途中でやめた対戦は、次に対戦するときに「負け」になる

## v8.4 で変わったこと
- ミニゲーム「にゃんこバッティング」（baseball.html）を追加。トレーニング → ミニゲーム からひらく
  - キャッチャーの後ろから見た画面。画面をおしたまま動かして黄色いカーソルを合わせ、指をはなすとスイング（ピッチャーが投げる前にはなしたら振らない。PCは矢印キー＋スペース）
  - 投手は3匹：柴犬（初級・ストレート/カーブ）／ブルドッグ（中級・＋スライダー）／ハスキー（上級・＋フォーク）。上の投手ほど球が速く、変化球とボール球が多い
  - 自分の猫の能力（装備ボーナスこみ）が効く：ちから＝飛距離、すばやさ＝カーソルの大きさ、たいりょく＝タイミングのゆるさ（どれも 数値÷(数値+60) で、上がるほどゆるやかに効く）
  - 猫はうしろ姿で、毛色＝猫の種類、服・手袋・頭＝いまの着せかえ。背中に名前とレベル
  - 10球で ホームラン100・長打50・ヒット30・ファウル5点。コイン＝合計点×投手の倍率（1／1.2／1.5）÷8（1回の上限50、ミニゲームの1日の回数に数える）。投手ごとのベストはアプリに保存
- nyankaloMini.info() が `cat`（name / breed / level / pow / spd / sta / head / top / hand / shirt / gloves）も返すようになった（ほかのミニゲームでも使える）

## v8.5 で変わったこと
- にゃんこバッティングの操作を変更：「スイング」ボタンをなくし、画面をおしたまま動かしてカーソルを合わせ、指をはなすとスイング（投げる前にはなしたら振らない）

## v8.6 で変わったこと
- さんぽモード（GPS）を追加：ホームの「歩数」→「🐾 さんぽモード（GPS）」
  - アプリを開いたまま歩くと、地図（OpenStreetMap）に道のりを描き、距離 ÷ 歩幅（身長×0.45）で歩数にする。1000歩ごとのごほうびは今までと同じ
  - GPSの誤差が30mより大きい点・その場のゆれ・秒速4.5m（約16km/h）より速い区間（乗り物）は数えない
  - 画面を消したり、ほかのアプリに切りかえると止まる（スマホのブラウザの制限）。もどったとき、歩く速さ（約9km/h以下）なら はなれた場所までのまっすぐの距離を足す
  - さんぽ中は画面が消えないようにする（対応しているスマホだけ）。道のりは保存せず、歩数だけ保存する
- 1日の歩数 ＝「手で入力」と「さんぽモード」の大きいほう（ヘルスケアの歩数にはさんぽの分も入っているので、足すと二重になるため）

## v8.7 で変わったこと
- 歩数の手入力をなくした。歩数はさんぽモード（GPS）だけで数える（ホームの「歩数」をタップするとさんぽモードがひらく）。前に手で入れた歩数はそのまま残る
- さんぽモードの地図に「お宝」（肉球の宝箱）：自分のまわり80〜250mに5個出て、30m以内まで歩くと拾える
  - 中身：コイン10〜30（70%）／スタミナドリンク（20%）／プロテイン（8%）／金のサンドバッグ（2%）。1日10個まで
  - 乗り物の速さのときは拾えない。400mはなれたお宝は近くに出しなおす。入れない場所に出たら「入れかえ」（30秒に1回）
  - 「いちばん近いお宝：北東へ120m」と出るので、地図が出ないときも探せる。近づくとブルッとふるえる
  - 数字は data.js の TREASURE で変えられる
- ミッション：「5,000歩あるく」→「さんぽで2,000歩あるく」、「さんぽでお宝を3つ拾う」（50コイン）を追加

## v8.8 で変わったこと
- 着せかえに「コスチューム」（全身の着ぐるみ・コスプレ）を追加。更衣室のいちばん上。着ている間は 頭・服 の見た目をかくす（能力のボーナスはそのまま）
  - カエルのレインコート（N）・くまの着ぐるみ（N）・恐竜パーカー（R）・コックさん（R）・魔法使い（SR・マント）・宇宙飛行士（SR・ヘルメットとリュック）
  - 福袋（ガチャ）から出る。絵はぜんぶオリジナル（cat.js の suitHead＝頭、suitBack＝体のうしろ。服の色は petcat.css の .wear-suit-○○）
  - ホーム・更衣室・対戦の猫、にゃんこバッティングのうしろ姿にも出る
  - コスチュームを増やすとき：data.js の WEAR に slot: 'suit' で1行、cat.js の suitHead（と必要なら suitBack）に絵、petcat.css に服の色

## v8.9 で変わったこと
- バックアップ・復元：「せってい」→「データ」
  - 「保存」：全データ（猫・コイン・道具・着せかえ・記録・写真・対戦ID）を1つのファイル（nyankalo-backup-日付.json）にする。スマホでは共有シート（「ファイルに保存」・LINE など）、PCではダウンロード
  - 「えらぶ」：バックアップファイルを選ぶと、中身（保存日・猫・コイン・記録の日数）を見せてから上書きして読みなおす。にゃんカロのファイルでない・こわれている・新しいバージョンのものは読みこまない
  - はじめての設定（名前を入れる画面）からも復元できる（機種変更したとき用）
  - 使いはじめて7日たって、7日以上バックアップしていないと、週に1回お知らせが出る
  - iPhone で「ホーム画面に追加」していない人には、追加するようにすすめる文を出す
