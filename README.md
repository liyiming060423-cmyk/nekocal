# にゃんカロ

ごはんを撮って、歩いて、筋トレして育てる猫の育成ゲーム（PWA）。

## ファイル
| ファイル | 中身 | 担当の目安 |
|---|---|---|
| index.html | 画面の骨組み | 画面担当 |
| style.css | 色・大きさ・配置 | デザイン担当 |
| data.js | アイテム・値段・ミッション・クイズ問題などの数字、猫の種類（CATS） | 企画担当（ここだけ直せばバランス調整できる） |
| cat.js | 骸骨・爆発の絵、頭の着せかえの絵 | 絵担当 |
| petcat.js / petcat.css | イラスト猫の動き・タップ反応・着せかえの色 | 絵担当・プログラム担当 |
| ○○-body.png / -tail.png / -shirt.png / -gloves.png | 猫のイラスト（体・しっぽ・服・手袋に分けた透過PNG）。○○＝tabby（茶トラ）/ white（白猫）/ longwhite（白い長毛猫）/ grey（灰色の長毛猫） | 絵担当（同じ名前で差しかえ） |
| home-bg.jpg | ホームとタイトル画面の背景 | 絵担当（同じ名前で差しかえ） |
| sagase.html / sagase.css | ミニゲーム「お題の猫を探せ！」（組員作）。コインはアプリのコインにたまる（1回最大50） | ミニゲーム担当 |
| dash.html | ミニゲーム「にゃんこダッシュ」（組員作）。拾ったコインがアプリにたまる（1回最大50） | ミニゲーム担当 |
| slot.html / slot-bgm.mp3 | ミニゲーム「にゃんこスロット」（組員作）。アプリのコインをかける（1日のもうけ上限100）。BGMは組員が用意した曲を軽くしたもの | ミニゲーム担当 |
| gym-bg.jpg / shop-bg.jpg | ジムとガチャのお店の絵 | 絵担当 |
| app.js | 計算・保存・各タブの動き | プログラム担当 |
| sw.js / manifest.webmanifest | オフライン起動・アプリ名とアイコン | 触らなくてOK |

## 更新するとき
ファイルを GitHub にアップロードし直したら、**3か所の版の数字をそろえて上げる**：sw.js の `VERSION`、data.js の `APP_VER`、index.html と sagase.html・slot.html の `?v=`（古いキャッシュと新しいファイルが混ざって画面がくずれるのを防ぐため）。

## 猫を増やすとき
1. 4枚の透過PNG（体・しっぽの先・服・手袋。4枚とも同じ大きさ、高さ813）をほかのファイルと同じ場所に入れる。服はオレンジ、手袋は茶色にそろえる（着せかえの色はフィルターで変えるため）
2. data.js の `CATS` に1匹ぶん書き足す（名前・絵の幅・頭の位置・タップの当たり判定）
3. sw.js の一覧に4枚を足して、VERSION を上げる

## v8 で変わったこと
- タイトル画面（毎回）→ はじめての人は「名前 → 猫えらび → からだのこと」
- 猫が4種類に。せっていの「猫の種類」でいつでも変えられる
- 赤・金のグローブで茶色が残るバグを直した（手袋の絵を切り抜き直し）
- ミニゲーム「本物の猫を探せ！」を追加（クリアで 10/30/50 コイン、ミニゲーム全体で1日3回まで）
- AIで調べたごはんに 糖質・たんぱく質・脂質 を表示（りれき に1日の合計とバランス）
- ホームの背景を組員のデザイン画から作った絵に

## v8.1 で変わったこと
- 版の数字（?v=）をつけて、更新直後に古いCSSと新しいHTMLが混ざって画面がくずれる問題を防いだ
- 猫が骸骨・爆発に近づくとSOS（体型 ±70 で1回、±90 で2回目）。猫のセリフ・鳴き声・振動・画面のふちが赤く光る・通知（通知をオンにしているとき）
- ごはんに「間食」を追加（りれき は 朝・昼・夜・間食 の4つ。ミッション「朝・昼・夜」には数えない）
- 写真つきでごはんを記録すると、ミニゲームの報酬つきプレイ +1回（1日3回まで）
- 「お題の猫を探せ！」を新しい版に入れかえ、「にゃんこダッシュ」「にゃんこスロット」を追加
